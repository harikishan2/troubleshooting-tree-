02 / Algorithm comparison

Visiting rules, uses, and complexity.

TraversalVisiting ruleTypical useTimeAuxiliary space
PreorderRoot → Left → RightParent-first processing; tree representationO(n)O(h)
InorderLeft → Root → RightSorted output in a binary search treeO(n)O(h)
PostorderLeft → Right → RootChild-first processing; deleting treesO(n)O(h)
Level-orderLevel by levelBreadth-first exploration using a queueO(n)O(w)

n = number of nodes; h = tree height; w = maximum number of nodes at one level. Worst-case auxiliary space can be O(n).

03 / Python implementation

Copy the code and run it with Python 3.

from collections import deque

class Node:
    def __init__(self, data):
        self.data = data
        self.left = None
        self.right = None

def preorder(node):
    if node is None:
        return
    print(node.data, end=" ")
    preorder(node.left)
    preorder(node.right)

def inorder(node):
    if node is None:
        return
    inorder(node.left)
    print(node.data, end=" ")
    inorder(node.right)

def postorder(node):
    if node is None:
        return
    postorder(node.left)
    postorder(node.right)
    print(node.data, end=" ")

def levelorder(root):
    if root is None:
        return
    queue = deque([root])
    while queue:
        node = queue.popleft()
        print(node.data, end=" ")
        if node.left:
            queue.append(node.left)
        if node.right:
            queue.append(node.right)

root = Node("A")
root.left = Node("B")
root.right = Node("C")
root.left.left = Node("D")
root.left.right = Node("E")
root.right.left = Node("F")
root.right.right = Node("G")

print("Preorder: ", end=""); preorder(root); print()
print("Inorder: ", end=""); inorder(root); print()
print("Postorder: ", end=""); postorder(root); print()
print("Level-order: ", end=""); levelorder(root); print()

04 / Viva preparation

Quick answers to common demonstration questions.

What is a binary tree?

A non-linear data structure where each node has at most two children: left and right.

Why do all traversals take O(n) time?

Every traversal visits each of the n nodes exactly once.

Why does level-order use a queue?

A queue follows First In, First Out (FIFO), allowing nodes to be processed level by level.

What is the limitation of this model?

It uses a small fixed tree. A real support system needs more cases and verified diagnostic rules.
